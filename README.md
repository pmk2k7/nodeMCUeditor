NodeMCU Uploader (nodeMCUeditor.py)
Tkinter மற்றும் pyserial, esptool நூலகங்களைப் (libraries) பயன்படுத்தி NodeMCU / ESP8266 சாதனங்களுக்கு ஃபார்ம்வேர் (Firmware) அல்லது பைனரி கோப்புகளை எளிதாகப் பதிவேற்ற உதவும் எளிய வரைகலை (GUI) பயன்பாடு ஆகும்.   
PY

🚀 முக்கிய அம்சங்கள் (Features)
சாதனத் தெரிவு (Device Selection): கணினியுடன் இணைக்கப்பட்டுள்ள COM போர்ட்களை (COM Ports) தானாகவே கண்டறிந்து பட்டியலிடுகிறது.   
PY

புதுப்பித்தல் பொத்தான் (Refresh Devices): இணைக்கப்பட்ட சாதனங்களை உடனடியாக ஸ்கேன் செய்து புதுப்பிக்க உதவுகிறது.   
PY

கோப்புத் தேர்வு (File Selection): பதிவேற்றத் தேவையான பைனரி (.bin) கோப்புகளை எளிதாகத் தேர்ந்தெடுக்கலாம்.   
PY

தானியங்கிப் பதிவேற்றம் (Automated Flash & Upload): சாதகமான இணைப்பை ஏற்படுத்தி, ஃபிளாஷை அழித்து (Erase Flash), புதிய ஃபார்ம்வேரைத் துல்லியமாக எழுதுகிறது.   
PY

பயனர் நட்பு இடைமுகம் (User-Friendly UI): பிழைக் கண்டறிதல் மற்றும் வெற்றிகரமான செய்திகளை பாப்-அப் (Pop-up) மூலம் காட்டுகிறது.   
PY

📦 தேவையான நூலகங்கள் (Prerequisites)
இந்த நிரலை இயக்க உங்கள் கணினியில் பைத்தானுடன் பின்வரும் நூலகங்கள் நிறுவப்பட்டிருக்க வேண்டும்:

Bash
pip install pyserial
pip install esptool
🛠️ பயன்பாடு (How to Use)
உங்கள் NodeMCU சாதனத்தை USB கேபிள் மூலம் கணினியுடன் இணைக்கவும்.

இந்த பைத்தான் நிரலை இயக்கவும்:

Bash
python nodeMCUeditor.py
திறக்கும் வரைகலை சாளரத்தில் (GUI Window), "Refresh Devices" பொத்தானை அழுத்தி உங்கள் போர்டைத் தேர்ந்தெடுக்கவும்.   
PY

"Select File to Upload" பொத்தானைக் கிளிக் செய்து, நீங்கள் பதிவேற்ற விரும்பும் .bin (Binary) கோப்பைத் தேர்ந்தெடுக்கவும்.   
PY

இறுதியாக "Upload to NodeMCU" பொத்தானைக் கிளிக் செய்து ஃபார்ம்வேரைப் பதிவேற்றவும்.   
PY

💻 நிரல் குறியீட்டு அமைப்பு (Code Structure)
NodeMCUUploader வகுப்பு: முழுமையான வரைகலை சாளரம் மற்றும் சாதன மேலாண்மைக் கட்டுப்பாடுகளைக் கொண்டுள்ளது.   
PY

refresh_devices முறை: serial.tools.list_ports உதவியுடன் இணைக்கப்பட்ட போர்ட்களைப் பட்டியலிடுகிறது.   
PY

upload_to_nodemcu முறை: esptool உதவியுடன் சாதனத்துடன் இணைப்பை ஏற்படுத்தி, நினைவகத்தை அழித்து புதிய கோப்பை எழுதுகிறது.   
PY
